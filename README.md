# 🤖 AI Software Engineer Agent

An autonomous multi-agent AI software engineering system built using LangGraph, Streamlit, and LLMs.

## Features

- 🌐 Research Agent
- 🧠 Planner Agent
- 💻 Coder Agent
- ⚙️ Executor Agent
- 🔍 Reviewer Agent
- 🐛 Debugger Agent
- 👤 Human Review Agent
- 🧪 Tester Agent
- 📚 Documentation Agent
- 📁 File Writer Agent
- 🔄 Live Agent Execution
- 💬 ChatGPT-style Interface
- 📂 File Explorer
- 📥 Download Generated Files

## Tech Stack

- Python
- LangGraph
- LangChain
- Streamlit
- Groq API
- DuckDuckGo Search

## Installation

```bash
git clone https://github.com/YOUR_USERNAME/AI-Software-Engineer-Agent.git

cd AI-Software-Engineer-Agent

pip install -r requirements.txt

streamlit run ui/streamlit_ui.py
```
